# Worked Examples

Use these examples to calibrate answer shape, density, and practical specificity. Do not copy them blindly; adapt the structure to the user's premise.

## Example 1: Hunter Regressor Growth Curve

User request:

```text
헌터물 회귀자 주인공 성장곡선 설계해줘.
```

Recommended response shape:

```markdown
## 타입 진단
이 주인공은 `회귀 최적화형 헌터 + 약랭크 이상치 + 길드 밖 변수` 조합이 가장 강합니다. 초반 사이다는 "남들이 모르는 게이트 규칙을 먼저 써서 낮은 랭크 판정을 뒤집는 장면"에서 나오고, 긴장감은 회귀 지식이 바뀌는 순간부터 유지합니다.

## 성장곡선
| 구간 | 능력 보상 | 지위 보상 | 자원 보상 | 부담/대가 |
| --- | --- | --- | --- | --- |
| 1-5화 | 낮은 랭크로 C급 게이트 생존 | 구조자/목격자 1명 확보 | 첫 희귀 부산물 | 측정 이상자로 기록 |
| 6-15화 | 과거 공략법 응용 | 소형 길드 스카우트 | 숨겨진 보스 드롭 | 공략 정보가 부분적으로 어긋남 |
| 16-25화 | 파티 지휘 능력 증명 | 공개 랭크 재검사 압박 | 전용 장비 재료 | 대형 길드가 계약/감시 시도 |

## 다음 천장
다음 천장은 더 센 몬스터가 아니라 `회귀 전에는 없던 게이트 변종`입니다. 주인공이 아는 공략이 70%만 맞고, 남은 30%를 현장 판단으로 메워야 합니다.
```

## Example 2: Villainess Survival Reward Structure

User request:

```text
악역영애 생존형 주인공 보상구조 잡아줘.
```

Recommended response shape:

```markdown
## 타입 진단
`빙의 악역영애 + 평판 역전형 + 궁정 생존 약자`로 잡는 것이 좋습니다. 보상은 호감도보다 먼저 `처형 루트가 하나씩 닫히는 감각`이어야 합니다.

## 보상구조
| 보상 | 독자 보상 | 세계 내 보상 | 대가 |
| --- | --- | --- | --- |
| 사망 플래그 회피 | 생존 안도감 | 사건 당일 알리바이 | 누군가 주인공의 변화를 의심 |
| 하녀/시종 1명 확보 | 외로움 완화 | 내부 정보망 | 그 인물이 약점이 됨 |
| 피해자에게 보상 | 평판 역전의 첫 증거 | 증언 가능 인물 | 과거 악행이 더 구체화됨 |
| 약혼 계약 조항 수정 | 주도권 회복 | 법적 방패 | 상대 가문이 반격 명분 확보 |

## 금지 패턴
모두가 갑자기 "알고 보니 착했다"고 믿으면 긴장감이 무너집니다. 첫 25화에서는 딱 한 명만 믿고, 두 명은 이용하며, 한 명은 끝까지 과거 죄를 묻는 구조가 좋습니다.
```

## Example 3: Chaebol Possession Mid-Arc Repair

User request:

```text
재벌물 빙의자 주인공이 중반부터 너무 쉽게 이겨. 고쳐줘.
```

Recommended response shape:

```markdown
## 문제
현재 문제는 주인공의 능력이 강한 것이 아니라, 돈과 정보가 곧바로 승리로 연결되는 구조입니다.

## 최소 수정
다음 승부는 "돈을 벌 수 있느냐"가 아니라 "합법적으로 지배권을 행사할 수 있느냐"로 바꿉니다.

## 보상 리듬 교체
| 기존 보상 | 새 보상 | 대가 |
| --- | --- | --- |
| 투자 성공 | 의결권 확보 | 이사회 의심 |
| 주가 예측 | 감사 자료 확보 | 내부고발자 보호 의무 |
| 경쟁자 압도 | 계열사 운영권 | 실적 책임과 언론 노출 |

## 다음 3화 적용
| 화 | 장면 | 독자 보상 | 남는 문제 |
| --- | --- | --- | --- |
| 1 | 주인공이 미래 지식으로 산 지분이 의결권 제한 주식임을 알게 됨 | 쉬운 승리 차단 | 법무팀 필요 |
| 2 | 버려진 계열사의 실제 현금흐름을 찾아냄 | 정보 사이다 | 기존 임원 반발 |
| 3 | 이사회에서 작은 운영권만 따냄 | 현실적 진전 | 이제 실적으로 증명해야 함 |
```

## Example 4: Academy Munchkin Tension

User request:

```text
아카데미 먼치킨인데 긴장감이 죽지 않게 해줘.
```

Recommended response shape:

```markdown
## 타입 진단
`숨은 먼치킨 + 결함 있는 천재 + 시험 제도 밖 변수`가 좋습니다. 전투는 이기게 두되, 전투 승리가 곧 사회적 승리가 되지 않게 해야 합니다.

## 긴장 유지 장치
| 장치 | 작동 방식 | 보상 |
| --- | --- | --- |
| 부분 공개 | 한 명의 교수만 진짜 실력을 봄 | 독자는 우월감을 얻고, 주인공은 감시를 얻음 |
| 랭킹 제한 | 실전 능력은 높은데 이론/출석/가문 점수가 낮음 | 시험 사이다가 남음 |
| 팀 과제 | 혼자 이기면 감점, 약한 팀원을 살려야 통과 | 먼치킨이 리더로 확장 |
| 금지 기술 | 강하지만 쓰면 가문/탑/협회가 반응 | 힘의 가격 유지 |

## 다음 천장
다음 천장은 더 강한 학생이 아니라 `주인공이 혼자 압도하면 오히려 실패하는 공개 팀 시험`입니다.
```

## Example 5: Genre-Only Starter

User request:

```text
헌터물 기본 성장곡선 잡아줘.
```

Recommended response shape:

```markdown
## 장르 기본값
| 항목 | 선택 |
| --- | --- |
| 독자 약속 | 낮은 평가를 뒤집는 게이트 사이다 |
| 기본 주인공 조합 | 약랭크 이상치 + 숨은 변수 + 길드 압박 |
| 위치강조 | 측정 체계가 설명 못 하는 인물 |
| 첫 위기 | 낮은 랭크라 구조 대상에서 제외됨 |

## 첫 25화 프리셋
| 구간 | 사건 기능 | 독자 보상 | 반작용 |
| --- | --- | --- | --- |
| 1-5화 | 측정 실패와 첫 생존 | 약자 판정 뒤집기 | 기록 이상 |
| 6-10화 | 두 번째 게이트에서 반복 가능한 강점 증명 | 실력이 우연이 아님 | 스카우트 접근 |
| 11-15화 | 파티원 한 명을 살리며 목격자 확보 | 인정의 첫 씨앗 | 소문 |
| 16-25화 | 재측정/계약 압박 | 공개 지위 상승 | 대형 길드 견제 |
```

## Example 6: Extra Survival

User request:

```text
소설 속 엑스트라 생존형 주인공을 성장형으로 만들고 싶어.
```

Recommended response shape:

```markdown
## 타입 진단
`엑스트라 생존형 + 플롯 정보 보유자 + 안전 설계자`가 좋습니다. 성장 보상은 강한 스킬보다 "죽을 가능성을 줄이는 영구 장치"가 먼저입니다.

## 성장 방향
| 단계 | 성장 | 보상 | 대가 |
| --- | --- | --- | --- |
| 초반 | 죽음 플래그 회피 | 안전 루트, 숨을 장소, 조력자 | 원작 흐름이 작게 어긋남 |
| 중반 | 플롯 밖 판단 | 주인공 일행의 신뢰 일부 | 메인 캐릭터가 의심 |
| 후반 | 사건 설계자 | 재난을 미리 배치/차단 | 원작 지식이 크게 무효화 |

## 핵심 규칙
엑스트라 생존형은 계속 도망만 치면 피로합니다. 10화 안에 하나의 안전 자산을 영구화하세요: 방, 계약, 조력자, 돈줄, 이동수단, 정보망 중 하나가 좋습니다.
```

## Answer Calibration Rules

- Start with a one-sentence diagnosis when the user asks in Korean.
- Prefer 2-4 compact tables over long explanation.
- Include at least one "do not do this" warning when repairing tension.
- For vague requests, give a usable first 25-episode shape.
- For broken outlines, preserve the premise and change the pressure source.
- End with next ceiling or next 3-15 episode application, not a generic summary.
